Question 2: Primitive vs Reference Data Types
1. int age = 20;
Answer: Primitive data type.

The int data type is a primitive type used to store whole numbers.

2. double salary = 1500000.50;
Answer: Primitive data type.

The double data type is a primitive type used to store decimal numbers.

3. char grade = 'A';
Answer: Primitive data type.

The char data type is a primitive type used to store a single character.

4. boolean passed = true;
Answer: Primitive data type.

The boolean data type is a primitive type used to store either true or false.

5. String name = "Namegabe Ntaboba Moise";
Answer: Reference data type.

String is a reference data type because it represents an object.

6. int[] marks = {70, 80, 90};
Answer: Reference data type.

An array is a reference data type because it is an object that stores multiple values.

Difference Between Primitive and Reference Data Types
Primitive data types store simple values directly. Examples include int, double, char, and boolean.

Reference data types store a reference to an object in memory. Examples include String, arrays, and objects created from classes.

Question 5: Short Questions
1. What is a variable in Java?
A variable is a named memory location used to store a value. The value of a variable can be changed during program execution.

Example:

int age = 20;

Here, age is a variable that stores the value 20.

4. What is the difference between == and =?
The = operator is an assignment operator. It is used to assign a value to a variable.

Example:

int age = 20;

The == operator is a comparison operator. It is used to check whether two values are equal.

Example:

age == 20

5. What is the purpose of the Scanner class?
The Scanner class is used to receive input from the user, usually through the keyboard.

For example:

Scanner input = new Scanner(System.in);
int age = input.nextInt();

It can be used to read different types of input such as integers, decimal numbers, and text.

6. Why is Integer.parseInt() commonly used with BufferedReader?
BufferedReader reads input using readLine(), which returns the input as a String.

Integer.parseInt() is used to convert the String into an int so that the value can be used in mathematical calculations.

Example:
