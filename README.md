Learning Outcomes
This practical assignment demonstrates the ability to:

Declare and use Java variables and data types.
Distinguish between primitive and reference data types.
Apply different types of Java operators.
Accept user input using the Scanner class.
Accept and process user input using BufferedReader.
Programs Included
1. StudentInfo.java
This program demonstrates the use of different Java data types:

String – Student name
int – Age
double – Average mark
char – Gender initial
boolean – Scholarship status
2. Calculator.java
This program accepts two integers and performs:

Addition
Subtraction
Multiplication
Division
Remainder
It also demonstrates:

Arithmetic operators
Relational operators
Logical operators
Assignment operators
Ternary operator
Bitwise operator
3. StudentMarksScanner.java
This program uses the Scanner class to receive:

Student name
Registration number
Marks for three subjects
It calculates:

Total marks
Average mark
Pass or fail status
A student passes when the average mark is 50 or above.

4. StudentMarksBufferedReader.java
This is a version of the Student Marks program that uses BufferedReader.

The marks entered as Strings are converted into integers using:

Integer.parseInt()
